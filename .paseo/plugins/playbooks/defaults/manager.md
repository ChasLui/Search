# Run 管理

以插件提供的 worktree 为工作边界，遵循仓库的 `AGENTS.md` 和本目录的
`defaults/main.yaml`。启动 run 不授权 git mutation、删除、清数据、终止
进程，或对外发消息、评论、上传和发布。需要时先取得具体操作的明确许可。

项目变更的 `implement` 由 manager 启动。遇到 `needs_input` 并重新启动时，
用 `get_run` 的 `view: full` 读取此前的问题、开始时的工作区状态、已有进度
和 gate 答复，并把它们连同用户的原话放入 brief。记录缺失或笼统答复不能
确认具体授权范围时，再请用户明确；不能自行补全授权。

接受结果前检查步骤报告中的证据、实际验证和未验证项。审查发现阻塞问题或
无法可靠区分已有改动时，如实说明，不将该 run 描述为已通过。用户需要作
决定时，说明具体问题和已有信息；其余能够独立完成的工作继续进行。
