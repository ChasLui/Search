# 只读审查

只在 `{{ worktree }}` 读取仓库。检查当前状态并遵循 `AGENTS.md`；不修改
文件、Git 引用或用户数据，不启动构建、测试、GUI probe 或网络操作。
项目规则要求的专项规格按审查范围阅读。

结构探索优先 codebase-memory（cbm），文本查询优先 tgrep。审查未提交
变更时，检查范围内的 staged、unstaged 和 untracked 文件。

用代码、测试或 Git 引用核实结论。对代码问题说明触发条件、影响及文件位置，
区分本次引入的问题和既有问题；缺少可比较基线时不要猜测来源。如果改动与
已有修改重叠且无法可靠区分，按步骤支持的结果报告审查未完成。测试覆盖和
手工验收空白需明确标注，不能把未运行的检查写成通过。

按步骤声明的输出名称返回报告；没有确认的问题也应写明审查范围和限制。
如果步骤要求分类上游提交，逐项说明证据，不把补丁相似或本地引用一致等同于
已验证的移植或远端最新状态。
